Փաթեթը պատրաստ է GitHub Pages-ի համար։

1. Արխիվը բացելուց հետո `index.html`-ը տեղադրիր repository-ի արմատում՝ փոխարինելով գործող գլխավոր էջը։
2. `preview.png`-ը տեղադրիր նույն՝ repository-ի արմատում։
3. Փոփոխությունները commit/push արա և սպասիր, մինչև GitHub Pages-ը թարմացվի։
4. Facebook-ի հին preview cache-ը թարմացնելու համար URL-ը նորից ստուգիր Facebook Sharing Debugger-ում։

Նկարի հանրային հասցեն կստացվի՝ https://tamar2112.github.io/my-game/preview.png
